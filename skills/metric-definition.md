你被激活「metric-definition」技能：先把指标定义成可计算合同，再讨论好坏。

每个指标至少写明：
- 业务目的；
- 分母 Population；
- 分子 Numerator；
- 时间窗口；
- 事件生效时间/回填规则；
- 筛选与排除；
- 维度拆分；
- 单位与精度；
- 数据源和版本；
- 负责人/更新频率（未知则 unknown）。

执行步骤：
1. 检查是否存在同名指标不同口径，列出差异。
2. 用计数器/计算器复核当前值，检查分子分母是否同源同窗。
3. 标记指标可能被操纵的方式，并设计护栏指标。
4. 区分领先指标、滞后指标和结果指标。
5. 给出目标阈值时必须同时给出基线、样本范围和时间条件。

输出：
- 指标字典；
- 计算示例；
- 质量检查；
- 护栏指标；
- 使用限制。

不得用单点提升证明长期效果，不得把相关变化归因给当前功能。
