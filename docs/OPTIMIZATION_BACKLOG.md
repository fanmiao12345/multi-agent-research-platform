## 处理纪律

1. D 阶段发现影响本步可运行性、数据/权限正确性的缺陷，转当前步骤修复并记录理由。
2. Q 阶段先冻结和测基线，再定位问题、修改、复验；保留失败样本与未知成本，不修改参考答案迎合结果。
3. 性能改善必须同时说明质量和费用变化；无收益如实记录。
4. 新的必做功能须回到主计划确定范围；不能用“优化”无限扩项。
