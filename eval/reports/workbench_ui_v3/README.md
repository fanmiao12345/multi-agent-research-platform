# Research Console V3：浏览器自检证据（2026-09-22）

用途：记录第三版前端（Research Console V3）融合进 `src/interfaces/web/workbench.py` 后的离线浏览器自检结果。
对应开发记录见 `docs/IMPLEMENTATION_LOG.md` 同日「前端改用 Research Console V3（用户提供）+ 合并补齐 + 清理」条目。

## 怎么生成的

```powershell
.venv\Scripts\python eval\reports\workbench_ui_v3\ui_probe_v3.py
```

`ui_probe_v3.py` 用**合成任务数据**（临时 workspaces + 桩数据，不接触真实 `workspaces/`、不发真实模型请求）
启动工作台，然后用 Playwright 走完整点击路径：首页 → 示例任务 → 高级设置抽屉 → "先看计划" →
任务中心（筛选/搜索）→ 任务详情（结果 / 点击 `[E-001]` 看证据 / 资料与产物 / 执行过程 / 版本与改稿）→
待补充任务提交补充 → 真实提交一次（Mock 模式）并确认跳转到任务详情 → 运行观测 → 配置与评测。

`probe_result.txt` 是脚本输出的读数（首页最近任务、方案预览、任务表、详情摘要、证据定位、来源预览、
补充前后状态、提交后 URL、配置与统计、数据边界卡，以及 `PROBLEMS` 一栏——为空表示 0 控制台错误、0 个 HTTP ≥400）。

## 边界

这是**离线自检**：合成数据 + 桩件，用于确认界面结构、点击路径与状态流转可用。
真实模型、真实资料、真实搜索的浏览器人工验收属于 Q4 用户试用，不能用这些截图替代业务验收。
V3 默认"真实模型"模式；`.env` 未配置时首页会显示"配置不可用"并禁用"开始任务"，这是有意行为。
