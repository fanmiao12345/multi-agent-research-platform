# 教育领域使用生成式AI的收益与风险：证据核查与提纲

核查范围与证据说明
本报告仅依据给定素材包与提纲，不引用外部事实【[E-003]】〔事实〕。现有资料明确称未提供教育领域使用生成式AI的收益或风险信息【[E-003]】〔事实〕，且仅凭本资料无法回答教育场景收益与风险，需补充其他来源【[E-005]】〔事实〕。因此，要完成该任务，需另找涉及生成式AI教育应用的资料【[E-034]】〔事实〕。证据强度上，现有材料多为缺口声明、原则性表述、工具介绍或官方页面线索，缺少教育场景直接实证〔推断〕。本章可核查范围为素材包已列证据，结论边界受此限制〔推断〕。

教育领域收益与风险的直接证据缺口
现有资料未提供教育领域使用生成式AI收益或风险相关信息【[E-009]】〔事实〕，也未提供生成式AI用于教育领域收益与风险的具体论述【[E-023]】〔事实〕。教育部门户首页仅为栏目与链接索引，未给出具体论述【[E-027]】〔事实〕。中国教育考试网资料不含生成式AI教育收益或风险证据【[E-033]】〔事实〕。此外，某影像创作工具资料仅介绍创作工具，未提供教育领域使用生成式AI收益或风险证据【[E-035]】〔事实〕。结合本资料未提供教育领域收益或风险信息【[E-003]】〔事实〕，可判断目前素材不能直接支持课堂收益或风险结论〔推断〕。是否有未列出的间接证据可支撑，未知〔未知〕。

生成式AI工具能力与教学素材的有限推测
Kling AI首页自称下一代AI创意工作室【[E-001]】〔事实〕，页面仅呈现创意圈、资产、Omni、生成、灵动画布、全部工具等栏目【[E-002]】〔事实〕；该资料未出现学校、教师、学生或课程等教育相关词语【[E-004]】〔事实〕。另有资料介绍AI图像生成与图片编辑在线工具，未涉及教育领域应用【[E-006]】〔事实〕，所列创作用途为个人或商业内容，未提及教学、学习场景【[E-007]】〔事实〕。即梦AI支持文/图生视频，输入文案或图片可快速生成视频片段【[E-036]】〔事实〕，可操控运镜、调节速度，动效连贯流畅自然【[E-037]】〔事实〕，支持首帧和尾帧图片输入，增强视频生成可控性【[E-038]】〔事实〕，支持中文提示词创作，语义理解能力更好【[E-039]】〔事实〕，绘画可用简单提示词生成图片并可进行创意改造【[E-040]】〔事实〕，智能画布集成拼图、局部重绘、一键扩图、图像消除和抠图等功能【[E-041]】〔事实〕。资料推测若用于教育，快速生成视频或图片可能辅助制作教学素材【[E-042]】〔推断〕。但该推测是否成立、对教学效果有无提升，缺少教师使用评价与对照研究〔未知〕。

AI与教育公共利益的原则性关联
UNESCO称AI等新兴技术应服务公平、机会与包容【[E-010]】〔事实〕，并称AI治理应反映所有国家优先事项【[E-011]】〔事实〕。相关资料称AI时代教育、信息诚信等构成当代挑战【[E-012]】〔事实〕，以“用新技术和AI学习”为社区影响事例【[E-013]】〔事实〕，并称UNESCO第4届AI伦理全球论坛强化全球合作【[E-014]】〔事实〕。但该资料仅泛称AI，未出现生成式AI一词【[E-017]】〔事实〕。数字学习周上教育部长呼吁AI时代坚持教育作为公共利益【[E-018]】〔事实〕。教科文组织通过教育、科学、文化和传播促进全球和平【[E-022]】〔事实〕。这些可支持AI服务教育公共利益的泛原则〔推断〕，但不能直接证明生成式AI在教育中的收益或风险〔推断〕。

非教育场景的AI风险与信息诚信参考
资料提示AI生成结果发布前须完成事实、权利与质量检查【[E-008]】〔事实〕，指出信息丰富不保证质量或准确性【[E-015]】〔事实〕，称数字平台可能削弱独立新闻的条件【[E-016]】〔事实〕。资料还称AI通过深度伪造、人肉搜索、骚扰等加剧针对女记者虐待【[E-019]】〔事实〕，教科文组织呼吁打击人工智能助长的性别暴力【[E-020]】〔事实〕，调查显示近3/4受访女记者曾面临网络暴力，1/4遭受人身或死亡威胁【[E-021]】〔事实〕。这些风险与信息诚信、新闻与性别暴力场景相关〔事实〕；将上述风险直接推及课堂缺少证据，只能作为外溢参考〔推断〕。
