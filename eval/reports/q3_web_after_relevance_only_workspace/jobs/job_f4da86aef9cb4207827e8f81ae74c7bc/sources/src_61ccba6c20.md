# 欧盟概况

（最近更新时间：2026年7月）

【成 员】27国：奥地利、比利时、保加利亚、塞浦路斯、捷克、克罗地亚、丹麦、爱沙尼亚、芬兰、法国、德国、希腊、匈牙利、爱尔兰、意大利、拉脱维亚、罗马尼亚、立陶宛、卢森堡、马耳他、荷兰、波兰、葡萄牙、斯洛伐克、斯洛文尼亚、西班牙、瑞典

【人 口】4.5亿

【面 积】410万平方公里

【国内生产总值】17.94万亿欧元（2024年）

【总 部】比利时首都布鲁塞尔

【主要网址】

https://www.consilium.europa.eu/en/european-council/ （欧洲理事会）

https://commission.europa.eu/index_en （欧盟委员会）

https://www.europarl.europa.eu/portal/en （欧洲议会）

https://www.eeas.europa.eu/_en（欧盟对外行动署）

【盟 旗】蓝底上12颗金色五星构成的圆环

【盟 歌】贝多芬第九交响曲中《欢乐颂》的主旋律

【庆典日】“舒曼日”5月9日

【轮值主席国】塞浦路斯（2026年上半年）、爱尔兰（2026年下半年）

【发展简史】1950年5月9日，法国外长舒曼发表声明（史称“舒曼计划”），建议法德两国建立煤钢共同体。1952年7月，法国、西德、意大利、荷兰、比利时和卢森堡正式成立欧洲煤钢共同体。1958年1月，6国成立了欧洲经济共同体和欧洲原子能共同体。1967年7月，3个共同体的主要机构合并，统称欧洲共同体。1993年11月，《欧洲联盟条约》（又称《马斯特里赫特条约》）生效，欧洲共同体演化为欧洲联盟（简称“欧盟”）。2002年1月欧元顺利进入流通。2009年《里斯本条约》生效后，欧盟具备了国际法主体资格，并正式取代和继承欧共体。《里斯本条约》并首次就成员国退出欧盟相关程序作出规定。

欧盟共经历了7次扩大：1973年英国、爱尔兰、丹麦加入；1981年希腊加入；1986年西班牙、葡萄牙加入；1995年奥地利、芬兰、瑞典加入；2004年5月1日，波兰、匈牙利、捷克、斯洛伐克、爱沙尼亚、拉脱维亚、立陶宛、斯洛文尼亚、塞浦路斯、马耳他10国入盟；2007年1月1日，罗马尼亚、保加利亚入盟；2013年7月1日，克罗地亚入盟。

2020年1月31日，英国正式脱离欧盟。

目前，土耳其、北马其顿、黑山、塞尔维亚、阿尔巴尼亚、乌克兰、摩尔多瓦、波黑、格鲁吉亚是入盟候选国。

【内部建设】欧洲一体化建设半个多世纪以来在曲折中不断取得积极进展。欧盟是目前世界上地区一体化程度最高的国家集团。欧盟先后建立了关税同盟，实行了共同贸易政策、农业和渔业政策，统一了内部大市场，基本实现了商品、人员、资本和服务的自由流通。建立了经济与货币联盟，在欧元区内统一了货币。一体化建设逐步向外交、安全、司法、内务等领域拓展，并不断取得进展，欧盟通过《阿姆斯特丹条约》和《尼斯条约》，陆续将“申根协议”纳入欧盟法律框架，把民事领域司法合作纳入欧盟机制。2009年《里斯本条约》生效后，欧盟选举产生了首任欧洲理事会常设主席范龙佩和首任欧盟外交与安全政策高级代表兼欧委会副主席阿什顿。2010年3月，欧盟提出了对外行动署组建方案，次年行动署主要职位任命和机构组建工作初步完成。欧债危机爆发后，欧盟进一步推动相关改革，包括积极推动银行联盟、资本市场联盟、能源联盟和单一市场建设，推动绿色和数字双转型，加强安全防务等领域合作。2020年以来，欧盟共同发债取得新突破，财政预算持续增加，以安全、竞争力和绿色发展为三大支柱不断推进各项政策，更加重视经济安全，出台《外国补贴条例》、《反胁迫工具》等一系列经贸政策工具箱，致力于加强战略自主。

【主要机构】

（1）欧洲理事会（European Council），又称欧盟峰会。欧盟最高决策机构。欧洲理事会由成员国国家元首或政府首脑及欧洲理事会主席、欧委会主席组成。欧洲理事会设主席一职，任期2年半，可连任一届。现任主席为葡萄牙前总理科斯塔（António Costa），2024年12月就任，任期至2027年5月31日。

（2）欧盟理事会（Council of the European Union），又称部长理事会，欧盟立法与政策制定、协调机构。理事会由每个成员国各1名部长级代表组成，按不同议事领域由相应部长组成，除外长理事会由欧盟外交与安全政策高级代表主持外，理事会主席由轮值主席国担任，任期半年。

（3）欧盟委员会（European Commission），简称欧委会，欧盟立法建议与执行机构。本届委员会共27人，由每个成员国1名代表组成，其中主席1人，副主席6人。现任主席为德国前国防部长冯德莱恩（Ursula von der Leyen），2019年12月就任，2024年12月连任，任期5年。

（4）欧洲议会（European Parliament）。欧盟监督、咨询和立法机构。议员由成员国直接选举产生，任期5年。本届（第十届）议会于2024年7月正式成立，现有718名议员，8个党团。现任议长梅索拉（Roberta Metsola，马耳他籍），2022年1月当选就任，2024年7月连任，任期2年半。

（5）欧盟对外行动署（European External Action Service）。由欧盟外交与安全政策高级代表（兼任欧盟委员会副主席）领导，协调成员国外交政策。现任欧盟外交与安全政策高级代表为爱沙尼亚前总理卡拉斯（Kaja Kallas），2024年12月就任，任期5年。

【经 济】2025年欧盟和欧元区经济增长率分别为1.5％和1.4％。欧委会预测2026年欧盟和欧元区经济增长率分别为1.4％和1.2％。

【对外关系】欧盟对外行动署是欧盟对外关系的主管部门，下设10个总司：多边、人权与民主事务总司，非洲总司，美洲总司，亚太总司，欧洲与中亚总司，中东与北非总司，全球事务与战略沟通总司，和平、安全与防务总司，民事行动总司，资源管理总司，以及欧盟军事参谋部。权限包括传统外交政策以及发展政策、人权、军事安全、民事危机处理等领域。欧盟实施共同外交与安全政策，各成员国以政府间合作方式进行决策。

欧盟积极开展全方位外交，已同160多个国家建立了外交关系，与多方建立了战略伙伴关系、定期领导人会晤机制和各领域高层对话机制，同多国缔结了贸易协定、经贸合作协定、联系国协定或其他协定，与多个国际和地区组织建立了比较密切的关系。欧盟奉行有效多边主义，倡导自由贸易，积极引领国际能源及气候变化合作，强调维护联合国的地位和作用。2016年6月，欧盟发布题为“共同愿景、共同行动：一个更强大的欧洲”的外交与安全政策全球战略，以促进和平与安全、实现繁荣、推进民主、建立基于规则的国际秩序等四大共同利益为目标，以“有原则的实用主义”为对外行动基本纲领。2019年12月，欧盟机构决定将“实用主义、团结和伙伴关系”作为三大外交原则，强调欧盟要加强地缘政治属性，基于现实主义、内部团结和伙伴关系三个支柱，统筹用好贸易、投资、金融、规则等工具开展对外行动，成为“全面地缘政治参与者”。2021年12月以来，欧盟在“全球门户”战略下持续推进全球互联互通计划，提升国际影响力。2022年3月，批准“战略指南针”行动计划，规划欧盟未来10年安全和防务政策。2024年以来，先后通过《欧洲国防工业战略》《欧洲国防工业计划》《欧洲防务白皮书》《2030防务准备路线图》，意图以防务建设加强战略自主、提升竞争力。

欧盟重视欧美关系，双方在政治和安全上互为盟友，经济上互为最主要的贸易和投资伙伴，但在自由贸易、军费分担、气候变化、伊朗核等问题上也存在分歧。乌克兰危机以来，欧盟向乌克兰提供大量支持，对俄罗斯实施多轮制裁，对俄能源“降依赖”。欧盟关注中东和平进程，支持“两国方案”，是伊朗核问题全面协议的执行协调员，重视同中东国家在难移民、反恐、能源、经贸领域合作。欧盟不断加强同亚洲国家关系，出台“印太合作战略”，加快推进贸易、投资、科技、产供链合作，持续加强安全防务对话与合作。欧盟是非洲最大贸易伙伴、最大投资来源地和官方发展援助最大提供方，是中亚、拉美和加勒比海地区最大投资来源地，希望加强同地区国家在互联互通、关键原材料、基础设施、绿色转型等领域合作。
