小米Windows互联

小米手机与Windows系统电脑互联，实现文件传输、同时电脑上可直接操作小米手机。

下载 Windows 内测版

下载 Windows 版

* Windows 内测版需配合Xiaomi HyperOS 4及以上手机/平板使用，Windows 版需配合Xiaomi HyperOS 3 Beta 及以上手机使用

使用条件

使用互联功能时，电脑需安装并打开“小米互联服务”应用。

在AI对话框里使用同步手机通知、传手机/平板照片等 AI 跨设备能力，需将手机/平板升级至Xiaomi HyperOS 4 及以上，Windows系统更新至 Windows 10 64位1903 （10.0.18362）及以上版本，“小米互联服务”需更新至2.0.x及以上版本。

小米手机与电脑需要处于同一局域网。

确保小米手机“设置-设备互联”开关已开启。

此应用不适用于小米、Redmi系列笔记本

电脑与小米手机互传

小米手机分享给电脑：在相册或文件管理，选择图片或文件，点击发送，选择电脑设备进行发送。

电脑分享给小米手机：在小米互联服务应用内，选择发现的小米设备，选择图片、视频或文件并发送。

电脑操作小米手机

确认小米手机“设置-设备互联-妙享桌面”开关已开启。

在小米互联服务应用内，点击开启妙享桌面，拉起手机窗口，支持使用手机内的应用或文件。

支持通过“妙享桌面”左上角应用入口，独立打开小米手机最近应用。最多支持同时打开2个手机应用窗口
