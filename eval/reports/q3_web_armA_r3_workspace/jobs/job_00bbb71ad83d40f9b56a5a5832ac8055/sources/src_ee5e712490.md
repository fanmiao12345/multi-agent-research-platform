汉朝时期十大事件

楚汉之争

楚汉之争是西楚霸王项羽、汉王刘邦两大集团为争夺政权而进行的一场大规模战争，又名楚汉战争、楚汉争霸等等，从公元前206年打到公元前202年，这场战争中诞生了许多有名的战役和典故，如暗渡陈仓、井陉之战、垓下之战、鸿门宴、指鹿为马、破釜沉舟、背水一战、四面楚歌等等，小编相信这些至今仍被广泛使用的词汇大家很都熟悉，最终楚汉之争以项羽败亡，刘邦建立西汉王朝而告终，汉朝历史正式拉开帷幕。 【 详细>>】

诸吕之乱

刘邦登基后采取与民休息、清静无为、休养生息的黄老政策，刘邦死后刘盈继位，但是在此期间实际是吕后称制，然后吕后死后由于她在政时期培植起一个吕氏外戚集团，加剧了汉朝统治阶级内部的矛盾，而吕后没有完成她的政治计划就去世了，因此汉朝统治阶级内部矛盾骤然激化，马上就酿成了刘氏皇族集团与吕氏外戚集团的流血斗争，也就是西汉历史中著名的诸吕之乱，此后吕氏集团彻底被消灭，诸吕之乱的结束实际上迎来了后来西汉的文景之治这一稳定时期 【 详细>>】

七国之乱

七国之乱是发生在中国西汉景帝时期的一次诸侯国叛乱，汉景帝即位后御史大夫晁错提议削弱诸侯王势力、加强中央集权，这时吴王刘濞就联合楚王刘戊、赵王刘遂、济南王刘辟光等刘姓宗室诸侯王，以“清君侧”为名发动叛乱。由于梁国的坚守和汉将周亚夫所率汉军的进击，叛乱在三个月内被平定，七国之乱是地方割据势力与中央专制皇权之间矛盾的爆发，最终西汉中央政权获得了绝对胜利，中央集权的巩固使得西汉王朝的实力愈发强大，汉族人对匈奴的反攻也逐渐拉开序幕，对社会经济发展和政治稳固，起到了卓越的成效。 【 详细>>】

文景之治

文景之治是西汉历史时期公认的太平盛世，也是中华文明迈入帝国时代后的第一个盛世。匈奴虽然几次入寇中原但大多数时间里处于相对和平的状态，汉朝方面则不断积蓄国力，透过一系列措施来积极备战，随着生产日渐得到恢复并且迅速发展，出现了多年未有的稳定富裕的景象。人民的生活水平得到了很大程度的提升，汉朝的物质基础亦大大增强，文景之治不仅是中国历史上经济文化飞速发展的一个伟大时代，同时也是为后来汉武帝征伐匈奴奠定了坚实物质基础的养精蓄锐时期。 【 详细>>】

汉武盛世

汉武帝时期汉朝达到空前强大的程度，和约略同时期欧洲的罗马帝国并列为当时世界上最先进的文明及强大帝国，文学、史学、哲学、政治学、经济学、军事学等方面，在这一时期都有相当程度的发展，这一时期以汉族为主体的统一多民族国家得到空前的巩固，汉文化的主流形态基本形成，开启了中国文明富强的序幕。汉武帝时代的政治体制、经济形式和文化格局，对后世留下相当重要的历史影响。 【 详细>>】

张骞出使西域

张骞出使西域又称张骞通西域，指的是汉武帝时期希望联合月氏夹击匈奴，派遣张骞出使西域各国的历史事件，汉朝有什么大事件至今为人们所熟知的话，网编觉得这个算一件，本为贯彻汉武帝联合大月氏抗击匈奴之战略意图，但出使西域后汉夷文化交往频繁，中原文明通过“丝绸之路”迅速向四周传播，因而张骞出使西域这一历史事件便具有特殊的历史意义，张骞对开辟从中国通往西域的丝绸之路有卓越贡献，至今举世称道。 【 详细>>】

马邑之围

马邑之围又称马邑之战、马邑之谋，是著名的西汉历史事件，是公元前133年西汉在马邑策划的对匈奴的一场诱敌歼灭战，军臣单于贪图马邑城的财物，亲率10万大军进入武州塞后因消息泄露未能完成伏击，自此西汉开始与匈奴大规模交战。“马邑之围”的计划虽未成功，但却使汉朝结束了自西汉初年以来奉行的屈辱的“和亲”政策，同时也拉开了汉匈大规模战争的序幕，汉朝开始主动出击匈奴，派卫青、霍去病征伐，解除匈奴威胁，保障了北方经济文化的发展。 【 详细>>】

霍光辅政

霍光辅政是西汉重要的历史事件，因汉武帝为了打匈奴，通西域，再加上他的生活奢侈，喜欢讲排场，还迷信神仙，连年大兴土木，耗费了大量的人力、物力，刘彻死后年仅7岁的刘弗陵即位，是为汉昭帝，汉昭帝登基之初，由上官桀、金日磾、田千秋、桑弘羊和霍光5人共同辅政。但是在元凤元年爆发元凤政变，汉昭帝清醒地诛杀了上官桀等一批阴谋权臣，避免了霍光被冤杀，霍光得以继续辅佐汉昭帝治国，史称霍光辅政，霍光遵循汉武帝晚年的国策，对内继续休养生息，得以让百姓安居乐业，四海清平。 【 详细>>】

昭宣中兴

昭宣中兴指的是西汉汉昭帝和汉宣帝时代，此时的西汉处于恢复性稳定及发展阶段。在汉昭帝、汉宣帝治理下大汉出现了政治清明、社会和谐、经济繁荣，国家经济得到恢复，国势达到西汉极盛，四夷宾服、万邦来朝，使汉朝再度迎来了盛世，史称“孝宣之治”，出现了“吏称其职，民安其业”的景象，而且汉宣帝时期匈奴进一步衰落和分裂，南匈奴臣服于汉朝，自此汉匈战争告一段落。 【 详细>>】

王莽篡汉

汉代大事件中王莽篡汉是必须提的一件，汉宣帝死后汉元帝刘奭即位，西汉开始走向衰败，汉元帝柔仁好儒，导致皇权旁落，外戚与宦官势力兴起，国家已经呈现一片末世之象，民间“再受命”说法四起，太皇太后王政君派王莽接替董贤成为大司马并迎接刘衎，但是汉平帝已经沦为王莽的傀儡，年仅14岁的汉平帝病死后，王莽立仅两岁的刘婴为太子，自任“摄皇帝”，公元8年十二月王莽废除孺子婴的皇太子之位，建立新朝，西汉历史至此结束。 【 详细>>】
