# 工作台界面优化：浏览器自检证据（2026-09-22）

用途：记录"用户视角信息架构"这次界面优化的离线浏览器自检结果。对应开发记录见
`docs/IMPLEMENTATION_LOG.md` 2026-09-22「界面优化（用户视角信息架构）」条目。

## 怎么生成的

```powershell
.venv\Scripts\python eval\reports\workbench_ui_optimize\ui_probe.py
```

`ui_probe.py` 会用**合成任务数据**（临时 workspaces + 桩数据，不接触真实 `workspaces/`、
不发真实模型请求、不读取 `.env` 密钥）启动工作台，然后用 Playwright 走完整点击路径：
切换四个视图、点任务行看交付与依据、勾选"允许联网研究"+"先看计划再开始"生成方案、
在"待补充"任务里提交补充信息、最后真实提交一次任务确认自动跳转与选中。

## 边界

这是**离线自检**：合成数据 + 桩件，用于确认界面结构与点击路径可用。
真实模型、真实资料、真实搜索的浏览器人工验收属于 Q4 用户试用，不能用这些截图替代业务验收。
