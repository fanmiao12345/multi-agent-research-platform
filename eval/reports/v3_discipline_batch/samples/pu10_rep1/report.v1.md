# 网页缓存视频保存位置：基于现有材料的可定位说明

## 已有信息
- 以QQ浏览器为例，保存视频文件的地址为SD卡→QQBrowser→视频【E-001】〔事实〕。
- 下载成功后，视频保存到手机SD卡→QQBrowser→视频中【E-004】〔事实〕。
- 下载操作上，打开视频后点击右下角下载按钮【E-002】〔事实〕。
- 在弹出页面中点击此视频即可下载【E-003】〔事实〕。
- 因此，在具备SD卡的手机且使用QQ浏览器时，网页缓存视频的保存位置可定位到SD卡→QQBrowser→视频【E-001】；下载完成后也落在该路径【E-004】〔推断〕。

## 无法完成的部分
- 其他浏览器或非QQ浏览器的网页缓存视频保存在哪里，现有材料未提供其他浏览器保存路径的说明，不能据此确认【未知】。
- iOS或非SD卡设备的网页缓存视频保存在哪里，现有材料未提供非SD卡设备保存路径的说明，不能据此确认【未知】。
- 现有材料只给出以QQ浏览器为例的路径【E-001】，并描述下载成功后保存到手机SD卡路径【E-004】；因此上述保存位置结论以QQ浏览器、手机且具备SD卡为条件〔推断〕。
- 若需扩展到其他浏览器或非SD卡设备，应补齐对应保存路径材料，并对该条件下的最终位置进行复核〔推断〕。
