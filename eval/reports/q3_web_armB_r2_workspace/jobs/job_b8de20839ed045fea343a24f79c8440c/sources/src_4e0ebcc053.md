# ​2003年梅艳芳去世后，医生：她的病可以治好，但因一事她放弃

2025-01-10 12:48:30 来源: 华人星光 陕西 举报

0

2003年，40岁的 梅艳芳 过世后没多久，她的主治医生在一次采访中坦白：“其实梅姑的病是有机会治好的，但就为了一件事，她主动放弃了治疗……”

梅艳芳在2001年确诊癌症后，她只把自己的病情告诉了自己的好友兼设计师 刘培基 ，其他朋友她全身是刻意隐瞒。

因为她想要采取保守疗法，也不希望因为生病而影响到工作。

所以，当时没有人知道梅艳芳的病情，除了刘培基，没有好朋友为她分忧排解，宽慰她。

梅艳芳一边忍受着高强度的工作，一边又饱受病痛的折磨，但即便如此，她也不从不轻易对人诉苦，而是选择自己苦苦支撑。

在2002年3月底，为了庆祝自己正式出道20周年，梅艳芳策划了的“极梦幻 演唱会 ”。

舞台上， 张国荣 作为嘉宾登上最后一场的演唱会舞台，与梅艳芳共同演绎《 芳华绝代 》和《缘分》，堪称精彩绝伦。

两个人在完全没有彩排的情况下，默契程度能够做到这样，简直让人拍案叫绝。

然而，那时的张国荣已经患上了抑郁症，梅艳芳并不知情，而当时的梅艳芳也同样被癌症折磨，张国荣对此也一无所知。

大概好朋友的性格多少有些相似，宁愿自己忍受疾病的纠缠，也不愿去打扰对方，不愿让对方为自己担心。

那时候的他们谁也不曾想过，这居然就是两个人此生的最后一场合作。

当时梅艳芳拖着疲惫的身体坚持演出到最后，舞台效果特别棒，但是细心的歌迷还是看到了梅艳芳眼神中的一丝丝伤感。

当时身边的工作人员，都以为那是梅艳芳工作太累而呈现出的疲惫感。但其实，那是梅艳芳得知自己病情加重而透露出来的失落。

所以她在表演舞台上几度落泪。

2003年4月1日，张国荣从酒店高楼上一跃而下，猝然离世。

挚友的突然离世对她来说又是一个沉重的打击，她连续几天不吃不喝，整个人消瘦了太多。

一向活泼洒脱的她瞬间好像变了个人，如同枯木一般活着，身体状况也是一天不如一天。

那时的她，肿瘤出血情况已经十分严重，可她在接受化疗的同时也忙着一大堆工作。

2003年这一年里，她投身抗击非典公益事业，远赴日本为初恋情人过生日，最后坚持举办自己的告别演唱会。

为了演唱会顺利进行，她暂停了化疗导致病情加重。

但这个时候没人能劝说得了梅艳芳，可惜在最后一场演唱会结束没几天，她因癌细胞转移到肺部导致肺衰竭，于2003年12月30日不幸离世。

就这样，梅姑结束了她短暂又璀璨的一生！

其实当时，梅艳芳被查出癌症的时候，只是早期子工颈癌，当医生跟她讲是有可能治疗好的，只是需要把子工切除掉，梅艳芳听后果断拒绝了。

在原生家庭中没有得到过太多爱护的梅艳芳，内心一直渴求的，就是和深爱的人结婚生子，拥有一个幸福完整的家。

如若失去子宫，就意味着她再也无法生儿育女，这是她无论如何也接受不了的。

殊不知，就是这样一个决定，为她的生命健康埋下了一个巨大的雷……

梅艳芳曾说，希望自己能在30岁前结婚，32岁生小孩，可是到最后，这个愿望还是没能实现。

虽然抱有遗憾，但是在告别演唱会上，她还是穿着一袭白色婚纱，将自己嫁给舞台，也算是给自己一个完好的结局。

那一幕看哭无数人，也成为至今都让人难忘怀的一个场面。

她生前曾有过一个疑问，当自己有朝一日离开娱乐圈，不知道会有多少人记得她？

也许她不曾想过，在她去世将近二十年后，我们不光记得她，还记得她无数个经典的代表作与代表曲目，更记得她为这个社会做出的无数善举。

大爱，梅姑！
