# 网页缓存视频保存位置资料整理

## 已有信息

就现有资料可确认：QQ浏览器保存视频文件地址为SD卡→QQBrowser→视频【E-001】〔事实〕；下载成功后视频保存到手机SD卡→QQBrowser→视频中【E-004】〔事实〕。因此，若问题中的网页缓存视频指通过QQ浏览器保存或下载的视频，其可定位位置为手机SD卡中的QQBrowser→视频目录【E-001】【E-004】〔推断〕。

下载方法方面，资料记载：打开视频后点击右下角下载按钮【E-002】〔事实〕；在弹出页面中点击此视频即可下载【E-003】〔事实〕。据此可推断，资料给出的操作路径是先打开视频，再通过右下角下载按钮和弹出页面完成下载【E-002】【E-003】〔推断〕；下载成功后的保存位置仍指向SD卡→QQBrowser→视频【E-004】〔事实〕。

上述位置仅来自QQ浏览器和手机SD卡场景的表达【E-001】【E-004】〔事实〕；资料未明确区分“网页缓存视频”与“下载保存视频”的路径差异【E-001】【E-004】〔未知〕。

## 无法完成的部分

资料只说明QQ浏览器在手机SD卡场景下的保存位置，即SD卡→QQBrowser→视频【E-001】〔事实〕，以及下载成功后保存到手机SD卡→QQBrowser→视频中【E-004】〔事实〕。它没有提供其他浏览器或非QQ浏览器的网页缓存视频保存路径【E-001】【E-004】〔未知〕；因此其他浏览器缓存视频保存在哪里，本报告无法据现有资料确认〔未知〕。它也缺少非SD卡存储路径的资料【E-001】【E-004】〔未知〕；因此iOS等无SD卡设备的缓存视频保存位置，本报告无法据现有资料确认〔未知〕。补齐方向为：其他浏览器缓存视频保存路径资料、非SD卡存储路径资料；补齐后需复核其他浏览器实际保存目录，以及无SD卡设备实际保存目录与可访问方式〔推断〕。
