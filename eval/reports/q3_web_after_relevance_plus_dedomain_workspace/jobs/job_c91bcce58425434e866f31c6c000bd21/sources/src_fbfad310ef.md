## The entire automation surface, all in Studio

Studio brings AI agents, RPA workflows, API integrations, apps, and process modeling together, so you ship faster, with full governance.

### Agentic process

Coordinate agents, robots, and people in one process

Built-in business rules, routing logic, and a full audit trail. Purpose-built for end-to-end processes like Order-to-Cash, Procure-to-Pay, and employee onboarding, where compliance, repeatability, and standardization are requirements, not nice-to-haves.

### AI agents

Production-grade agents, with guardrails built in

Start fast with pre-built templates or build from scratch in a low-code experience. Customize with instructions, context, tools, escalation paths, and evaluations. Get smarter guidance from Autopilot and Agent Score & Optimizer. Deploy to the UiPath governed runtime, no SDK required.

### RPA workflows

Industry-leading UI automation, supercharged by agentic AI

AI Computer Vision and robust selectors across Windows and macOS. Ready-to-use activities for UI automation, IT automation, IDP, Integration Service, and GenAI. ScreenPlay turns natural language into self-driving UI automations. Healing Agent adds intelligent self-healing at runtime.

### API workflows

Build, manage, and scale system-to-system integrations

API workflows run on demand, on schedule, or in response to real-time events. Agents and robots call them reliably. Abstract complex API chaining into composite, callable services. Autopilot generates workflows from natural language and creates expressions and docs as you build.

### Apps

An enterprise-grade front end for your automations

Low-code or coded. JS Apps (coming soon): next-gen low-code builder, JavaScript-powered, browser-native. RPA Apps: full RPA capabilities embedded in your apps. Coded apps (new): full creative control when UX outgrows the canvas. One-click deploy across desktop and mobile.

## UiPath Studio: common evaluation questions

Answers for developers, architects, and IT teams evaluating UiPath Studio.

Request demo

###### Is UiPath Studio free?

Yes. The UiPath Community Edition is a free version of Studio for individuals, students, and small teams. It includes Autopilot and access to Studio Desktop and Studio Web. Paid Enterprise tiers (Express, Basic, Plus, Pro) add governance, source control, advanced debugging, and CI/CD.

###### What’s the difference between Studio Desktop and Studio Web?

Studio Desktop is the Windows IDE for complex RPA, desktop automation, and coded C# workflows. Studio Web is the browser-based IDE for AI agents, API workflows, agentic process modeling, and apps, and runs on Windows and macOS. Same licensing, same governance, same platform.

###### Does UiPath Studio work on Mac?

Yes, through Studio Web. Studio Web is the browser-based IDE for agentic and API-first automation and runs on macOS as well as Windows. Studio Desktop is Windows-only.

###### What languages does UiPath Studio support?

C# for coded automations and coded apps. Python for coded agents (LangGraph, LlamaIndex, OpenAI Agents). JavaScript for coded apps. Low-code and AI-assisted modes generate workflows without requiring a language choice.

###### How is UiPath Studio governed and secured?

Every workflow, agent, and API call runs under platform governance: role-based access control, workflow analyzer rules, publishing policies, audit trails, and secret management. The same controls apply across agents, robots, APIs, and apps.

###### Where can I run automations built in UiPath Studio?

Run on Automation Cloud as SaaS, or self-host with Automation Suite across cloud, on-premises, or hybrid environments. Studio publishes to the same governed runtime in both cases.
